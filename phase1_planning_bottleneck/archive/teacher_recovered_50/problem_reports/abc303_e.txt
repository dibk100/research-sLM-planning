[Self-Generated Plan]
- **Core Algorithm**: Identify the center of the tree and determine the levels of the stars.
- **Decision Condition**: A vertex is a center if its degree is N-1.
- **Key Invariant**: The center is the only vertex with degree N-1, and all other vertices have degree 1.
- **Data Structures**: Use an adjacency list to represent the graph.
- **Edge Cases**: 
  - If N=3, the graph is a triangle, and the output should be [1].
  - If N=4, the graph is a path, and the output should be [1].
- **Time Complexity**: O(N)
- **Space Complexity**: O(N)

[Teacher Plan]
- Build the adjacency lists and start a breadth-first search from any vertex of degree 1, recording the depth of every vertex.
- The star centers are exactly the vertices whose depth is congruent to 1 modulo 3, and the level of such a star is the degree of that center.
- Correctness: a degree-1 vertex of T is an untouched star leaf, so its neighbour is a center at depth 1, that center's other leaves sit at depth 2, each added leaf-leaf edge moves to another star's leaf at depth 3, and its center appears at depth 4, repeating with period 3.
- Collect the degrees of all identified centers, sort them ascending, and print them separated by spaces.
- Only adjacency lists, a depth array and an iterative BFS queue are needed; recursion must be avoided because N can be 2*10^5.
- Time and memory are O(N).

for u, v in edges:
    adj_list[u-1].append(v-1)
    adj_list[v-1].append(u-1)

# Find the center of the tree
center = None

        center = i
        break

# Determine the levels of the stars

visited[center] = True

    levels[node] = level
    for neighbor in adj_list[node]:
        if not visited[neighbor]:
            visited[neighbor] = True
            dfs(neighbor, level + 1)

dfs(center, 0)

    if level > 0:
        star_count += 1

from collections import defaultdict, deque

def find_stars(N, edges):
    # Build adjacency list
    adj_list = defaultdict(list)
    for u, v in edges:
        adj_list[u].append(v)
        adj_list[v].append(u)
    
    # Initialize depth array
    depth = [0] * (N + 1)
    
    # Perform BFS starting from any vertex of degree 1
    queue = deque([v for v in range(1, N + 1) if len(adj_list[v]) == 1])
    while queue:
        current = queue.popleft()
        for neighbor in adj_list[current]:
            if depth[neighbor] == 0:
                depth[neighbor] = depth[current] + 1
                queue.append(neighbor)
    
    # Collect the degrees of all identified centers
    star_levels = []
    for v in range(1, N + 1):
        if depth[v] % 3 == 1:
            star_levels.append(len(adj_list[v]))
    
    # Sort the star levels and print them
    star_levels.sort()
    print(' '.join(map(str, star_levels)))

# Read input
N = int(input())
edges = [tuple(map(int, input().split())) for _ in range(N - 1)]

# Find and print the star levels
find_stars(N, edges)
