- **Core Algorithm**: The goal is to determine if the strings can be rearranged into a sequence where each string differs from the next by exactly one character.
- **Decision Condition**: For each pair of consecutive strings, check if they differ by exactly one character. If any pair does not meet this condition, output "No". If all pairs meet the condition, output "Yes".
- **Key Invariant**: The invariant is that for each pair of consecutive strings, they must differ by exactly one character.
- **Data Structures**: Use a list to store the strings.
- **Important Edge Cases**:
  - If \( N = 2 \), check if the two strings differ by exactly one character.
  - If \( N = 1 \), output "Yes" since there are no pairs to compare.
- **Time Complexity**: \( O(N \times M) \), where \( N \) is the number of strings and \( M \) is the length of each string.
- **Space Complexity**: \( O(N \times M) \), due to storing the strings.

    input = sys.stdin.read
    data = input().split()
    
    N = int(data[0])
    M = int(data[1])

    # Check if the first string can be transformed into the second string by changing exactly one character
    def can_transform(s1, s2):
        if len(s1) != len(s2):
            return False
        count = 0
        for i in range(len(s1)):
            if s1[i] != s2[i]:
                count += 1
        return count == 1
    
    # Check if all consecutive strings can be transformed into each other by changing exactly one character
    for i in range(N - 1):
        if not can_transform(strings[i], strings[i + 1]):
            print("No")
            return

def can_form_conforming_sequence(N, M, strings):
    # Generate all possible permutations of the strings
    for perm in permutations(strings):
        # Check if the permutation satisfies the condition
        for i in range(N - 1):
            if sum(perm[i][j] != perm[i + 1][j] for j in range(M)) != 1:
                break
        else:
            return "Yes"
    return "No"
