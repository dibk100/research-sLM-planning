- **Core Algorithm**: Use a sliding window approach to find the minimum number of operations required to remove all black cells.
- **Decision Condition**: For each position in the string, determine the minimum number of operations needed to make all cells from that position to the end white.
- **Key Invariant**: The invariant is that for each position, the minimum number of operations to make all cells from that position to the end white is calculated by considering the current window size and the number of black cells within it.
- **Data Structures**: Use a deque to efficiently manage the window of size $k$.
- **Edge Cases**: Handle cases where the entire string is white or where the string is entirely black.
- **Time Complexity**: $O(t \cdot n)$, where $t$ is the number of test cases and $n$ is the length of the string. This is because for each test case, we process each character once.
- **Space Complexity**: $O(n)$, due to the deque used to store the window of size $k$.

[Teacher Plan]
- Scan the string from left to right and greedily start an operation at the first black cell that is not yet covered.
- When s[i] is 'B', increment the counter and jump i to i + k; when s[i] is 'W', advance i by 1.
- Correctness: the leftmost uncovered black cell must be covered by some operation, and the window starting exactly at it covers a superset of the cells any other valid window could cover to its right.
- Edge cases: a string with no 'B' gives 0, and the last window may extend past the end of the string, which is harmless.
- No data structure beyond the input string and an index counter is needed.
- Time is O(n) per test case with O(1) extra memory; the sum of n is at most 2 * 10^5.

from collections import deque

def min_operations_to_remove_all_black_cells(t):
    for _ in range(t):
        n, k = map(int, input().split())
        s = input()
        
        # Initialize variables
        black_count = s.count('B')
        if black_count == 0:
            print(0)
            continue
        
        # Initialize deque to store the window of size k
        window = deque(s[:k])
        black_in_window = window.count('B')
        
        # Calculate the initial number of operations
        operations = black_in_window
        
        # Slide the window across the string
        for i in range(k, n):
            # Add the new character to the window
            new_char = s[i]
            window.append(new_char)
            
            # Remove the character that is no longer in the window
            old_char = window.popleft()
            
            # Update the count of black cells in the window
            if old_char == 'B':
                black_in_window -= 1
            if new_char == 'B':
                black_in_window += 1
            
            # Update the minimum operations
            operations = min(operations, black_in_window)
        
        print(operations)
