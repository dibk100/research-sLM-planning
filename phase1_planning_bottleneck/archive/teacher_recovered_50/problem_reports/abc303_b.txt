[Self-Generated Plan]
- **Core Algorithm**: Count the number of pairs of people who are not adjacent in any of the photos.
- **Decision Condition**: For each person, check if they are adjacent to any other person in any of the photos.
- **Key Invariant**: The invariant is that for each person, the number of photos where they are adjacent to another person is counted correctly.
- **Data Structures**: Use a list to store the positions of each person in each photo.
- **Edge Cases**: Handle cases where there are no adjacent people in any photo by ensuring the list is checked for each person.
- **Time Complexity**: O(N * M), where N is the number of people and M is the number of photos.
- **Space Complexity**: O(N * M), due to storing the positions of each person in each photo.

[Teacher Plan]
- Insert every adjacent pair of each photo into a set of unordered pairs, storing each pair with its smaller element first.
- The answer is N*(N-1)/2 minus the number of distinct pairs in that set.
- Correctness: a pair may be in a bad mood exactly when it never appears adjacent in any photo, so subtracting the observed adjacent pairs from all pairs counts them.
- Edge cases: the same pair can occur in several photos or in both orders, which the normalized set deduplicates.
- Use a Python set of tuples; N and M are at most 50 so the input is tiny.
- Time is O(N*M) and memory is O(N*M).

import sys

def count_bad_mood_pairs(N, M, photos):
    # Initialize a list to store the positions of each person in each photo
    positions = [[] for _ in range(N)]
    
    # Populate the positions list
    for i in range(M):
        for j in range(N):
            positions[photos[i] - 1].append(j)
    
    # Initialize the count of bad mood pairs
    bad_mood_pairs = 0
    
    # Check each person's positions
    for i in range(N):
        pos = positions[i]
        if len(pos) > 1:
            # Count the number of adjacent pairs
            for j in range(len(pos) - 1):
                if pos[j + 1] == pos[j] + 1 or pos[j + 1] == pos[j] - 1:
                    bad_mood_pairs += 1
    
    return bad_mood_pairs

# Read input

import sys
input = sys.stdin.read
data = input().split()
N = int(data[0])
M = int(data[1])
photos = [tuple(map(int, data[2 + i * N : 2 + (i + 1) * N])) for i in range(M)]

# Create a set of all adjacent pairs in all photos
adjacent_pairs = set()
for photo in photos:
    for i in range(len(photo) - 1):
        adjacent_pairs.add((min(photo[i], photo[i + 1]), max(photo[i], photo[i + 1])))

# Calculate the number of bad mood pairs
total_pairs = N * (N - 1) // 2
bad_mood_pairs = total_pairs - len(adjacent_pairs)

print(bad_mood_pairs)
