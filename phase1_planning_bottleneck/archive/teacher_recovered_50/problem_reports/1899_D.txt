- **Core Algorithm**: Use a hash map to count occurrences of each power of 2. For each unique power, calculate the number of pairs that can be formed using that power.
- **Decision Condition**: A pair $(b_i, b_j)$ satisfies the condition if $b_i^{b_j} = b_j^{b_i}$, which simplifies to $b_i = b_j$ because $b_i$ and $b_j$ are powers of 2.
- **Key Invariant**: The hash map ensures that we efficiently count occurrences of each power of 2.
- **Data Structures**: Use a dictionary to store the frequency of each power of 2.
- **Edge Cases**: Handle cases where there are no unique powers of 2 or when the input size is large.
- **Time Complexity**: $O(n + m)$, where $n$ is the number of test cases and $m$ is the total number of elements in all arrays combined.
- **Space Complexity**: $O(m)$, where $m$ is the total number of elements in all arrays combined.

[Teacher Plan]
- Substituting b = 2^a reduces the condition b_i^{b_j} = b_j^{b_i} to a_i * 2^{a_j} = a_j * 2^{a_i}.
- Since a / 2^a is strictly decreasing for a >= 2 and takes the same value 1/2 at a = 1 and a = 2, the equality holds exactly when a_i = a_j or the unordered pair is {1, 2}.
- Count the occurrences of each exponent value in a hash map; the answer is the sum of c * (c - 1) / 2 over all values, plus count(1) * count(2).
- Never compute 2^{a_i} because a_i can be as large as 10^9; only the exponents are used.
- Edge cases: n = 1 gives 0, and the answer can reach about 2 * 10^10, so it needs 64-bit integers.
- Time is O(n) per test case with O(n) memory; the sum of n is at most 2 * 10^5.

from collections import defaultdict

def count_pairs(n, a):
    # Dictionary to store the frequency of each power of 2
    power_count = defaultdict(int)
    
    # Count the frequency of each power of 2 in the array
    for num in a:
        power_count[num] += 1
    
    # Calculate the number of pairs (b_i, b_j) such that b_i = b_j
    # This is simply the number of unique powers of 2 squared
    return sum(count * (count - 1) // 2 for count in power_count.values())
