[Self-Generated Plan]
- **Core Algorithm**: Identify the rectangle containing the cookies and determine which square was eaten by Snuke.
- **Decision Condition**: The square eaten by Snuke is the first square encountered in the grid that does not have a cookie.
- **Key Invariant**: The rectangle containing the cookies is defined by the smallest `a` and `c` and the largest `b` and `d`.
- **Data Structures**: Use a single pass through the grid to find the rectangle and the eaten square.
- **Important Edge Cases**: 
  - If the grid is empty, the problem is invalid.
  - If the grid has only one cookie, it must be the only square in the grid.
- **Time Complexity**: O(H * W), where H is the number of rows and W is the number of columns.
- **Space Complexity**: O(1), as no additional space is used beyond a few variables.

[Teacher Plan]
- Scan the grid once and record the minimum and maximum row index and the minimum and maximum column index over all '#' cells.
- Those four values are exactly the original rectangle's borders, so scan that rectangle and print the 1-indexed coordinates of its single '.' cell.
- Correctness: the rectangle has height and width at least 2, so removing one cookie cannot shrink any of the four extreme rows or columns; the remaining cookies therefore span the original rectangle exactly.
- Edge cases: the eaten cookie may sit on a corner or an edge of the rectangle, which the argument above still covers; exactly one empty cell exists inside it.
- Only the grid rows as strings and four integer bounds are needed.
- Time is O(H*W) and memory is O(H*W).

import sys

def main():
    H, W = map(int, input().split())
    grid = [input() for _ in range(H)]
    
    # Find the rectangle containing the cookies
    a, b, c, d = float('inf'), 0, float('-inf'), 0
    
    for i in range(H):
        for j in range(W):
            if grid[i][j] == '#':
                a = min(a, i)
                b = max(b, i)
                c = min(c, j)
                d = max(d, j)
    
    # Find the square eaten by Snuke
    for i in range(a, b + 1):
        for j in range(c, d + 1):
            if grid[i][j] == '.':
                print(i + 1, j + 1)
                return

if __name__ == "__main__":
    main()

    for i in range(H):

                min_row = min(min_row, i)
                max_row = max(max_row, i)
                min_col = min(min_col, j)
                max_col = max(max_col, j)
    
    for i in range(min_row, max_row + 1):
        for j in range(min_col, max_col + 1):
            if grid[i][j] == '.':
                print(i + 1, j + 1)
                return

if __name__ == "__main__":
    main()
