[Self-Generated Plan]
- **Core Algorithm**: Use a stack to keep track of unmatched opening parentheses. For each character in the string:
  - If it's an opening parenthesis `(`, push it onto the stack.
  - If it's a closing parenthesis `)`, pop from the stack if it's not empty. If the stack becomes empty, it means there's no matching opening parenthesis for this closing one, so we can remove the substring from the start of the stack to the current position.
- **Decision Condition**: Continue processing the string until no more unmatched opening parentheses can be found.
- **Key Invariant**: The stack should always contain unmatched opening parentheses at the end of the string.
- **Data Structures**: Use a stack to store indices of unmatched opening parentheses.
- **Edge Cases**:
  - If the string is empty, return an empty string.
  - If the string contains only unmatched opening parentheses, return an empty string.
- **Time Complexity**: O(N), where N is the length of the string. Each character is processed at most twice (once for pushing and once for popping).
- **Space Complexity**: O(N) in the worst case, when all characters are opening parentheses.

[Teacher Plan]
- Process S left to right with a stack of output characters, and a second stack holding the positions in that output stack where each currently unmatched '(' sits.
- On '(' push the character and record its position; on ')' pop the most recent recorded position and truncate the output stack back to it, discarding the whole deleted substring; if no position is recorded, keep the ')' as an ordinary character.
- On a lowercase letter simply push it onto the output stack.
- Correctness: deleting an innermost parenthesized block equals removing everything after the matching '(' inclusive, and the result is order independent, so a single left-to-right stack pass reaches the final string.
- Edge cases: unmatched ')' before any '(' and unmatched '(' at the end both survive in the output; the answer may be empty, in which case print an empty line.
- Time is O(N) amortized and memory is O(N).

import sys

def process_string(s):
    stack = []
    result = []

    for i, char in enumerate(s):
        if char == '(':
            stack.append(i)
        elif char == ')' and stack:
            stack.pop()
        else:
            # If stack is empty, it means there's no matching opening parenthesis
            # for this closing one, so we can remove the substring from the start
            # of the stack to the current position.
            while stack:
                result.append(s[stack.pop()])
            result.append(char)

    # If there are still unmatched opening parentheses left in the stack,
    # they need to be removed.
    while stack:
        result.append(s[stack.pop()])

    return ''.join(result)

import sys

def process_string(S):
    output = []
    stack = []
    position_stack = []

    for i, char in enumerate(S):
        if char == '(':
            output.append(char)
            position_stack.append(len(output) - 1)
        elif char == ')':
            if position_stack:
                start = position_stack.pop()
                output = output[:start]
            else:
                output.append(char)
        else:
            output.append(char)

    return ''.join(output)
